Beetle Industries is an independent games studio building collectible titles inspired by net-art.

We're a small studio of artists and engineers working from the visual language of early net-art and image-board culture, making slow, considered systems out of fast, unruly imagery. The art comes first; the mechanics serve the cast.

## Title 01: Beetle Game

<p align="center">
  <img src="https://beetleindustries.com/assets/beetlegame-logo.png" alt="Beetle Game" width="280">
</p>

Our first release adapts hand-drawn beetles into an auto-battling card game: each beetle a unique card with elemental affinity, signature skill, and battle lineage.

| | |
| --- | --- |
| **Genre** | Collectible card game · auto-battler |
| **Platform** | Web (browser) |
| **Status** | In development, closed beta opening soon |
| **Site** | [beetlegame.com](https://beetlegame.com/) |

Collect beetles through pack openings, build six-member teams, and send them into automated battles built on an elemental advantage system: **Fire, Wind, Energy, Earth, Water**. Every card carries a signature skill, an affinity, and a battle history that persists across matches.
